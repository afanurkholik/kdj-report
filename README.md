# Kampus Dosen Jualan - Landing Page

Landing page sederhana (HTML + CSS, tanpa framework).

## Sebelum publish
1. Ganti `https://wa.me/6200000000000` di `index.html` dengan nomor WhatsApp admin.
2. Pastikan kamu punya hak untuk menampilkan contoh dokumen (lihat catatan di bawah).

## Deploy
- GitHub: buat repo baru, upload semua file (index.html, style.css, folder assets).
- Netlify: Add new site > Import from Git > pilih repo. Build command dan publish directory dikosongkan, atau isi publish directory dengan `.`.

## Catatan
Halaman 1 dan 7 ditampilkan apa adanya. Halaman 2-6 di-blur agar isi panduan tidak terbaca. Jangan ganti file blur dengan versi asli.
